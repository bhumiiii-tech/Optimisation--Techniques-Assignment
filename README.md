# Optimisation Techniques Assignment

Python implementation of two Operations Research methods:

## 1. Big-M Simplex Method
- Converts an LPP into standard form.
- Handles slack, surplus and artificial variables.
- Solves maximization and minimization problems using the Big-M method.

## 2. Transportation Problem
- Finds an Initial Basic Feasible Solution using Vogel's Approximation Method (VAM).
- Tests optimality and improves the solution using the MODI method.
- Handles iterative improvement of the transportation solution.

## Files

- `Big_M_Simplex.py` – Big-M Simplex implementation
- `Transportation_VAM_MODI.py` – VAM and MODI implementation

## Language

Python 3
